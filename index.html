GitHub Sync (Gist)

Synchronisiere deine Einnahmen sicher zwischen Handy und PC über ein geheimes GitHub Gist. Niemand außer dir hat Zugriff.

So einfach geht's:
  1. Gehe auf GitHub zu Developer Settings → Tokens (classic).
  2. Erstelle einen Token mit dem Haken bei gist.
  3. Füge den Token oben ein und klicke auf „Neuen Gist automatisch anlegen“.
  4. Auf dem 2. Gerät: Token & die erstellte Gist-ID einfügen. Fertig!
